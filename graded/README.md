## Flujo recomendado

1. Abre una actividad con el botón de Colab.
2. Selecciona **Archivo -> Guardar una copia en Drive**.
3. Resuelve los ejercicios en tu copia de Drive.
4. Ejecuta todas las celdas antes de entregar.

Las actividades calificadas no contienen las respuestas del instructor ni las pruebas ocultas.
