## 📝 Consejos Útiles

### Guardar tu Trabajo
- Opción 1: **Archivo → Guardar una copia en Drive** (recomendado)
- Opción 2: Presiona `Ctrl + S` (guarda automáticamente en Drive)
- Opción 3: **Archivo → Descargar** (descarga a tu computadora)

### Ejecutar Código
- Presiona `Shift + Enter` en una celda para ejecutarla
- O haz clic en el botón ▶ a la izquierda
- Para ejecutar todas: **Runtime → Run all**

## ❓ Preguntas Frecuentes

**P: ¿Necesito tener Python instalado?**  
R: ¡No! Colab lo instala automáticamente.

**P: ¿Qué pasa si cierro la pestaña?**  
R: Si guardaste en Drive, tu trabajo está seguro. Si no, se pierde.

**P: ¿Puedo trabajar sin internet?**  
R: Necesitas internet para abrir Colab, pero luego puedes descargar y trabajar offline.

**P: ¿Hay límite de tiempo?**  
R: Colab te da ~12 horas por sesión (suficiente para nuestros ejercicios).

**P: ¿Puedo colaborar con otros?**  
R: Sí, comparte el link de tu Drive con otros estudiantes.

**P: ¿Qué hago si se desconecta?**  
R: Recarga la página (el código que ejecutaste se conserva).
