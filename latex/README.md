## Overleaf
1. Comprime la carpeta del ejemplo como `.zip`.
2. Overleaf → **New Project → Upload Project**.
3. Abre el archivo `.tex` principal.
4. Presiona **Recompile**.
5. Modifica una parte pequeña y vuelve a compilar.

**LaTeX es una herramienta, no el objetivo:** buscamos documentos científicos claros, consistentes y reutilizables.
